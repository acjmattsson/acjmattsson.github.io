## Öppna frågor till produktägaren

- **Kontakt-e-post** för support och integritetsfrågor. Supportsidan har nu GitHub Issues som enda kontaktväg. Det kräver ett GitHub-konto, och Apple vill att användare enkelt ska kunna nå utvecklaren.
- **Namn på personuppgiftsansvarig.** Policyn anger nu "acjmattsson". Använd gärna samma namn som säljarnamnet i App Store Connect.
